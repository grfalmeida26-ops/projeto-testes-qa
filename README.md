\# Projeto de Testes de QA



Este repositório foi criado para registrar meus estudos e minha evolução na área de Quality Assurance (QA).



\## Objetivo



Praticar a criação e documentação de testes de software, utilizando conceitos e ferramentas aplicadas no dia a dia de um profissional de QA.



\## Conteúdos do projeto



\- Casos de teste

\- Testes funcionais

\- Cenários em Gherkin

\- Registro de bugs

\- Testes automatizados
